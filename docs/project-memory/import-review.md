# Imported memory review

Knowledge from outside the repository, such as ChatGPT's saved memory or past chats, is compared with the repository here **before** it goes into the other files. Nothing is accepted without the owner's approval.

## How a review works
1. **Paste:** the owner pastes the outside memory into the session. It's never committed as-is.
2. **Remove:** personal information, credentials and anything unrelated to Penelope are dropped first.
3. **Compare:** each remaining item is checked against the code and docs and given a verdict:
   - **Matches:** already recorded, nothing to add.
   - **New:** not in the repo yet; proposed for a specific file, with a status (usually 📋 Planned or ❓ Undecided, never ✅ without code).
   - **Conflicts:** differs from the repo. The repo is shown next to the memory and the owner decides.
   - **Outdated:** superseded by later work; not imported.
4. **Approve:** the owner approves item by item, then the accepted items are added and committed.
